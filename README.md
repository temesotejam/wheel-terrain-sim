# wheel-terrain-sim

タイヤ／車輪と変形地盤の相互作用を、ブラウザ上で比較・可視化する軽量シミュレータです。

## 現在のモデル

初期版は、以下を組み合わせた簡易テラメカニクスモデルです。

- Bekker–Wong系 pressure–sinkage model
- Janosi–Hanamoto型 shear stress model
- 剛体車輪の接触弧を数値積分
- 荷重に釣り合う沈下量を数値的に探索
- ラグ付きタイヤは簡易的な shear gain と lug penetration で近似
- 沈下量・スリップ率から残留轍と排土傾向を可視化する軽量履歴モデル
- 同じ轍を繰り返し走る再踏破モデル（締固め + 地盤撹乱の簡易履歴）

これはDEMのように土粒子を一粒ずつ解くモデルではありません。絶対値の予測よりも、**同一条件でのタイヤ形状比較と現象の可視化**を主目的にしています。

- スリップに応じた後方への排土・飛散粒子表現

- 再踏破後の5種類のタイヤ比較

## 轍モデルについて

現在の轍・排土表示はDEMではなく、計算された車輪沈下量に地盤別の残留係数とスリップ率を組み合わせた可視化用の簡易モデルです。画面右から未変形地盤が流入し、車輪の接触域で変形した地盤プロファイルが左へ流れて走行履歴として残ります。

したがって、轍深さや排土量は現段階では**相対比較用の指標**です。実測と合わせ込む場合は、地盤ごとの残留変形係数や排土係数を同定します。

## 再踏破モデルについて

`repass.js` では、同じ場所を繰り返し踏んだときの履歴を軽量に近似します。

- 踏破回数が増えると地盤の `kc` / `kphi` / cohesion を段階的に増やし、締固めを表現
- 締固めは回数とともに飽和
- スリップ率が高いほど締固め効果を弱める
- ラグが大きいほど地盤撹乱を増やし、締固め効果を弱める
- 各回で元の車輪–地盤モデルを再計算
- 残留轍は追加変形が徐々に小さくなる飽和モデルで累積

画面では、1〜8回の轍横断面を重ねて表示し、同時に瞬間沈下と推進力の変化を確認できます。

この履歴モデルも実測同定前の**比較用モデル**です。実際の地盤では含水率、締固め状態、粒度分布、横方向の土流動などで再踏破応答が大きく変わります。

## 自動テスト

GitHub Actions の `CI` workflow で以下を確認します。

```text
node --check app.js
node --check repass.js
node tests/repass-model.test.js
```

再踏破テストでは、累積轍が逆戻りしないこと、締固め剛性が破綻しないこと、高スリップ・ラグ付き条件でも有限値を維持することを確認します。

## GitHub Pagesの有効化

初回だけリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。

その後は `.github/workflows/pages.yml` が `feature/initial-terramechanics-sim` または `main` へのpushでサイトを公開します。

公開URLは通常:

`https://temesotejam.github.io/wheel-terrain-sim/`

## ローカルでの使い方

静的ファイルだけなので、`index.html` を直接開くか、任意のHTTPサーバーで配信できます。

例:

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 注意

地盤プリセットの値は、UIと相対比較を成立させるための暫定値です。実機予測に使う場合は対象地盤の pressure–sinkage / shear 特性、残留変形、再踏破時の締固め特性を実験で同定してください。
