# wheel-terrain-sim

タイヤ／車輪と変形地盤の相互作用を、ブラウザ上で比較・可視化する軽量シミュレータです。

## 現在のモデル

初期版は、以下を組み合わせた簡易テラメカニクスモデルです。

- Bekker–Wong系 pressure–sinkage model
- Janosi–Hanamoto型 shear stress model
- 剛体車輪の接触弧を数値積分
- 荷重に釣り合う沈下量を数値的に探索
- ラグ付きタイヤは簡易的な shear gain と lug penetration で近似
- 沈下量・スリップ率から残留轍と排土傾向を可視化する軽量履歴モデル
- 同じ轍を繰り返し走る再踏破モデル（締固め + 地盤撹乱の簡易履歴）
- 半径・幅・ラグ高さ・本数・角度を変更できるカスタムタイヤ形状モデル
- Bekker / shear / residual deformation パラメータを変更・保存できるカスタム地盤モデル
- Bekker–Wong系モデルと同条件で比較できる granular RFT proxy

これはDEMのように土粒子を一粒ずつ解くモデルではありません。絶対値の予測よりも、**同一条件でのタイヤ形状・地盤特性・モデル差の比較と現象の可視化**を主目的にしています。

## カスタムタイヤ形状エディタ

画面の「カスタムタイヤ形状」で次を変更できます。

- 半径: 60〜320 mm
- タイヤ幅: 25〜220 mm
- ラグ高さ: 0〜35 mm
- ラグ本数: 0〜36本
- ラグ角度: 進行方向に対して 0〜90°

値を変更すると自動的に `カスタムタイヤ` が選択され、通常の走行解析・スリップ率スイープ・タイヤ比較・再踏破解析へ同じ形状が反映されます。

`wheel-geometry.js` はラグ形状を軽量な有効係数へ変換します。現在は、ラグが高い・本数が多い・進行方向に対して横向きになるほど longitudinal traction 用の有効せん断指数が大きくなる比較モデルです。同時に転がり抵抗補正も増やします。

側面 / 上面プレビューは入力した形状を幾何的に描画しますが、**ラグ本数・角度が力へ与える影響は実測同定前の経験的な写像**です。したがって、現段階では「どの形状を本格DEMや実験へ回すか」を絞る用途を想定しています。

## カスタム地盤エディタ

画面の「カスタム地盤」で次を変更できます。

- `kc`: Bekker pressure–sinkage の cohesion 系係数
- `kφ`: Bekker pressure–sinkage の friction 系係数
- `n`: 沈下指数
- `cohesion c`: せん断強度の粘着力項
- `φ`: 内部摩擦角
- `K`: Janosi–Hanamoto のせん断変位係数
- `density`: 排土量指標で使う密度
- `rutFactor`: 走行後に残る轍の簡易残留係数
- `flow`: 排土・土流動の可視化係数

左のグラフは、現在選択しているタイヤ幅を使って `p(z)` を描きます。右のグラフは `τ_max = c + p tan(φ)` のせん断強度包絡を描きます。パラメータを動かすと `カスタム地盤` が選択され、通常解析・タイヤ比較・スリップ率スイープ・再踏破解析へ同じ地盤が反映されます。

地盤プロファイルはブラウザの `localStorage` に最大30件まで名前付きで保存できます。これはそのブラウザ内の保存であり、GitHubリポジトリや他端末へ自動同期するものではありません。

`soil-model.js` は入力値の範囲制限、pressure–sinkage、Mohr–Coulombせん断強度、プレビュー用の代表指標を担当します。`soil-editor.js` はUI・保存・既存解析への反映を担当します。

## RFT比較モデル

`rft-model.js` は granular Resistive Force Theory の構造を使い、車輪表面を多数の小要素へ分割して局所抵抗を積分します。各要素では地盤面からの深さ、車輪表面の向き、地盤に対する局所運動方向から抵抗力を求めます。

本来の granular RFT では、地盤ごとにプレート侵入実験などを行い `αx(β,γ)` / `αz(β,γ)` という応力/深さの角度マップを同定します。現段階ではその実測マップがないため、選択地盤の pressure–sinkage 曲線から25 mm基準の応力勾配を作り、簡単な角度依存を与えた **未校正RFT proxy** としています。

画面では次を確認できます。

- 車輪接触面のRFT局所抵抗ベクトル
- 各要素の地盤に対する表面運動方向
- 合計 `Fx` / `Fz` / 沈下量 / 必要トルク
- 同じ条件での Bekker–Wong 系モデルとの差
- スリップ率0〜80%に対する推進力と沈下量の2モデル比較
- RFT stress-per-depth の校正ゲイン変更
- 現在のBekker沈下量へRFT強度スケールだけを合わせる仮校正

仮校正は `α` の大きさだけを合わせるもので、RFTの角度依存マップを同定するものではありません。特に粘着力の大きい地盤では、乾燥粒状体向けRFTから外れるため参考値として扱います。

## 轍モデルについて

現在の轍・排土表示はDEMではなく、計算された車輪沈下量に地盤別の残留係数とスリップ率を組み合わせた可視化用の簡易モデルです。画面右から未変形地盤が流入し、車輪の接触域で変形した地盤プロファイルが左へ流れて走行履歴として残ります。

したがって、轍深さや排土量は現段階では**相対比較用の指標**です。実測と合わせ込む場合は、地盤ごとの残留変形係数や排土係数を同定します。

## 再踏破モデルについて

`repass.js` では、同じ場所を繰り返し踏んだときの履歴を軽量に近似します。

- 踏破回数が増えると地盤の `kc` / `kphi` / cohesion を段階的に増やし、締固めを表現
- 締固めは回数とともに飽和
- スリップ率が高いほど締固め効果を弱める
- ラグが大きいほど地盤撹乱を増やし、締固め効果を弱める
- 各回で元の車輪–地盤モデルを再計算
- 残留轍は追加変形が徐々に小さくなる飽和モデルで累積

画面では、1〜8回の轍横断面を重ねて表示し、同時に瞬間沈下と推進力の変化を確認できます。

この履歴モデルも実測同定前の**比較用モデル**です。実際の地盤では含水率、締固め状態、粒度分布、横方向の土流動などで再踏破応答が大きく変わります。

## 自動テスト

GitHub Actions の `CI` workflow で以下を確認します。

```text
node --check app.js
node --check repass.js
node --check wheel-geometry.js
node --check wheel-editor.js
node --check soil-model.js
node --check soil-editor.js
node --check editor-sync.js
node --check rft-model.js
node --check rft-compare.js
node tests/repass-model.test.js
node tests/wheel-geometry.test.js
node tests/wheel-editor-ui.test.js
node tests/soil-model.test.js
node tests/soil-editor-ui.test.js
node tests/rft-model.test.js
node tests/rft-ui.test.js
```

再踏破テストでは、累積轍が逆戻りしないこと、締固め剛性が破綻しないこと、高スリップ・ラグ付き条件でも有限値を維持することを確認します。

タイヤ形状モデルテストでは、スリック時の補正が1.0であること、ラグ高さ / 本数 / 角度による係数変化、入力クランプ、有限値維持を確認します。

地盤モデルテストでは、各パラメータの入力クランプ、pressure–sinkage の有限値と単調性、せん断強度、保存用プロファイル構造を確認します。

RFTテストでは、要求鉛直荷重との釣り合い、有限値、スリップに対する牽引力傾向、応力スケール増加による沈下低下、ラグ付き条件での安定性を確認します。UI wiringテストでは必要なCanvas・入力・スクリプト読込順を確認します。

## GitHub Pagesの有効化

初回だけリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。

その後は `.github/workflows/pages.yml` が `feature/initial-terramechanics-sim` または `main` へのpushでサイトを公開します。

公開URLは通常:

`https://temesotejam.github.io/wheel-terrain-sim/`

## ローカルでの使い方

静的ファイルだけなので、`index.html` を直接開くか、任意のHTTPサーバーで配信できます。

例:

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 注意

地盤プリセットとカスタム地盤の値は、実測同定なしでは絶対値予測に使えません。実機予測に使う場合は対象地盤の pressure–sinkage / shear 特性、RFTの `αx/αz` マップ、残留変形、ラグ形状係数、再踏破時の締固め特性を実験で同定してください。
