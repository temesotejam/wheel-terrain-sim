# wheel-terrain-sim

ブラウザだけで動く、タイヤ／車輪と変形地盤の相互作用を比較・可視化する軽量テラメカニクス・サンドボックスです。

**v1.0.0** では、タイヤ形状、地盤特性、スリップ率、荷重を変えながら、Bekker–Wong系モデルと granular RFT を同じ画面で比較できます。DEMのような粒子シミュレーションではなく、実験や本格解析へ進む前の**傾向比較・設計探索・可視化**を目的にしています。

## v1.0.0 でできること

- Bekker–Wong系 pressure–sinkage + Janosi–Hanamoto型 shear model
- 車輪接触弧の数値積分による沈下・推進力・必要トルク計算
- 回転タイヤ、接触反力、沈下、轍、排土のアニメーション
- スリップ率 0〜80% のスイープ
- 標準 / 幅広 / 細幅 / ラグ付き / 大径 / カスタムタイヤの比較
- 半径・幅・ラグ高さ・本数・角度を変更できるタイヤ形状エディタ
- `kc`, `kφ`, `n`, `c`, `φ`, `K`, 密度、轍係数、流動係数を変更できる地盤エディタ
- 地盤プロファイルのブラウザ保存 / 読込 / 削除
- 1〜8回の再踏破モデルと締固め・累積轍の可視化
- granular RFT の局所要素力可視化
- Bekker–Wong vs RFT の推進力・沈下・トルク比較
- RFT `αx(β,γ)` / `αz(β,γ)` ヒートマップ編集
- RFT αマップのCSV import / export、名前付きブラウザ保存
- Canvasアニメーションの8秒WebM保存
- GitHub Pages配信
- Node.jsだけで実行できる自動テスト

## まず使う

静的ファイルだけなので、`index.html` を直接開くか、ローカルHTTPサーバーで配信します。

```bash
python -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

GitHub Pagesを使う場合は、リポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** に設定してください。

公開URLは通常次です。

```text
https://temesotejam.github.io/wheel-terrain-sim/
```

## 解析モデル

### Bekker–Wong系モデル

主モデルでは、地盤のpressure–sinkage特性を

```text
p = (kc / b + kφ) z^n
```

で表し、接触面のせん断応力をJanosi–Hanamoto型モデルで計算します。荷重に釣り合う沈下量を探索し、接触弧全体を積分して前後力・鉛直力・トルクを求めます。

タイヤのラグ本数・角度は、現時点では有効せん断係数と転がり抵抗補正へ写像する比較用モデルです。

### 轍・再踏破モデル

轍表示はDEMではなく、計算された沈下量、スリップ率、地盤別残留係数から作る軽量履歴モデルです。

再踏破では、踏破回数に応じて地盤剛性が飽和的に増える締固めを表現しつつ、高スリップや大きなラグでは地盤撹乱によって締固め効果を弱めます。

### RFT

RFTでは車輪表面を小要素へ分け、局所深さ `|z|`、要素姿勢角 `β`、局所速度方向 `γ` から

```text
σx = αx(β,γ) |z|
σz = αz(β,γ) |z|
```

を求め、接触面全体で積分します。

v1では次の2方式を使えます。

1. **未校正proxy**: 選択地盤のpressure–sinkage特性からαの応力スケールを生成
2. **校正αマップ**: 編集またはCSV読込した `αx(β,γ)` / `αz(β,γ)` を直接積分

αマップの標準グリッドは、β=`-90°〜90°`を15°刻み、γ=`-180°〜150°`を30°刻みです。セル間は双線形補間します。

CSV形式は次です。

```text
beta_deg,gamma_deg,alpha_x_N_m3,alpha_z_N_m3
```

角度規約と校正手順の詳細は [`docs/RFT_ALPHA_MAP.md`](docs/RFT_ALPHA_MAP.md) を参照してください。

## カスタムタイヤ

画面の「カスタムタイヤ形状」で変更できます。

| パラメータ | v1範囲 |
|---|---:|
| 半径 | 60〜320 mm |
| タイヤ幅 | 25〜220 mm |
| ラグ高さ | 0〜35 mm |
| ラグ本数 | 0〜36本 |
| ラグ角度 | 0〜90° |

側面形状と接地面パターンをリアルタイム表示し、変更は通常解析・比較・再踏破・RFTへ反映されます。

## カスタム地盤

次を変更できます。

- `kc`, `kφ`, `n`
- cohesion `c`
- 内部摩擦角 `φ`
- Janosi–Hanamoto のせん断変位 `K`
- 密度
- 残留轍係数
- 土流動係数

pressure–sinkage曲線とせん断強度包絡をリアルタイム表示します。名前付き地盤プロファイルはブラウザの `localStorage` に保存されます。

## テスト

外部npm依存はありません。Node.js 20以降で、v1の全チェックを次の1コマンドで実行できます。

```bash
npm test
```

テスト内容:

- 全JavaScriptの構文チェック
- タイヤ形状モデル
- 地盤モデル
- 再踏破モデル
- RFT proxy
- RFT αマップ補間 / CSV往復
- αマップとRFTソルバの統合
- 各UIの配線確認
- `index.html` と動的に読み込むJS/CSSのサイト整合性確認

GitHub Actionsの `CI` でも同じ `npm test` を実行します。

## v1の位置づけと限界

このツールは**比較・可視化用**です。地盤プリセット、ラグ効果、轍、再踏破、RFT proxy の係数は、実測同定なしでは実機設計の絶対値予測に使用しないでください。

特に以下は実験校正が必要です。

- 対象地盤の `kc`, `kφ`, `n`
- cohesion / friction angle / shear displacement `K`
- 残留変形・再踏破時の締固め特性
- ラグ形状の効果係数
- RFT `αx(β,γ)` / `αz(β,γ)`

RFTは主に粒状体を対象にしたモデルなので、粘着性が強い地盤では適用範囲を慎重に判断してください。
